Cómo agregar o quitar un correo

1. Abrí Administrar destinatarios en GitHub e iniciá sesión con tu cuenta autorizada.

2. Para agregar una dirección, incorporá un elemento al listado destinatarios, por ejemplo:

{"email": "nuevo@bue.edu.ar", "activo": true}

3. Para suspender un destinatario, cambiá true por false. Para eliminarlo, quitá el elemento completo.

4. Guardá con Commit changes. El próximo envío leerá la lista actualizada.

Importante: no cambies la estructura JSON ni desactives el correo principal. Si la configuración es inválida, el envío se detendrá por seguridad.
